# CBE 1.8.8-recovery.1

This package is a recovery rebuild created after the original ChatGPT-hosted 1.8.8 archive became unavailable during a platform incident. It is reconstructed from the last materialized 1.8.4 source plus the recorded 1.8.5-1.8.8 source/audio corrections. It is not represented as byte-identical to the vanished archive.

Recovery targets retained here:
- one source-backed canonical MusyX renderer/cache identity on Windows and Android/non-Windows;
- 24/24 soundtrack cache transaction with redundant completion markers;
- old native/portable audio markers cannot satisfy canonical readiness;
- source-correct packed signed continuous pitch/mod decoding;
- source note-length key-off, same-note retrigger, sustain/RPN pitch automation, fresh DSP history and source loop boundaries;
- presentation-only Pokemon/trainer animation clocks invariant to battle fast-forward;
- audio attempt is required, while a proven renderer failure fails open to the verified visual runtime without repeating every boot.
