# Independent production review

No concrete unresolved regression was found in the reviewed production changes, including the final native scene-instance correction, checkpoint migration and Red victory hotfix. The companion JSON records the final reviewed production hashes and test results.

The static arena UV implementation agrees with the primary SysDolphin [`MakeTextureMtx`](https://raw.githubusercontent.com/doldecomp/melee/master/src/sysdolphin/baselib/tobj.c) composition: inverse UV scale with epsilon collapse to zero, repeat factors, negated texture Z rotation and XY translation, mirrored-T phase, then Scale × Rotation × Translation. Affine constant-Q stages are baked; unsupported projected/reflection coordinates stay unchanged. The opt-in also avoids extra metadata allocations during dense actor/effect extraction. The executable texture-state suite checks the binary descriptor offsets, identity sharing, UV-only channel changes, zero scale, unsupported stages, and canonical/packed metadata retention.

Both arena load routes retain colorMap/blending on each material group, independently of the shared image+sampler cache. Draws upload the group values and generated farfields reset them. Source unlit vertex/material color selection and shader alpha handling preserve the intended separate channels. The narrowly verified low ground-shadow exception matches between direct geometry and packed sidecars; other venues and raised helper planes retain their existing filters.

The original shipping marker selects a ten-source-arena refresh and retains Wildlands plus unrelated Pokemon, trainer, audio, transition and MoveFX caches. The exact delivered checkpoint marker selects Water/Deep instance repair only, preserving the other nine canonical arenas and packed sidecars. Its test fixture was captured from the saved checkpoint and checked against its actual exported marker. The optional two-Relic scope requires an exact previous marker with current global contracts and all venue files. Source extraction, sidecar generation, and late state/manifest failures leave or restore the recognized old marker and remove the full ready marker. Tests cover retries, missing venues, unrelated bytes, regenerated/reused sidecar counts, and second-boot reuse.

Trainer rendering uses a separate stable draw list of the original group objects. Native frame buffers continue binding by the original source group index; distinct frame-byte fixtures cover that alignment. Helper shader defaults prevent preceding material alpha from affecting shadows/balls. New sampler metadata is additive; the old-cache repeat fallback is limited to the verified Nascour material identity.

Red's victory visuals now use neutral native idle. The host still retains its terminal victory event. The shared performance path suppresses Red's victory action track and source gesture fallback, including after an active throw. Behavioral tests bind real trainer track buffers through the full held result for both player/enemy sides; other trainers' victories and Red's throw/defeat tracks remain unchanged. No trainer cache rebuild is required.

Shared actor idle notifications no longer restart an already-running idle clip. Terminal state clocks begin with the newly selected native pose, and sparse looping playback excludes rejected final samples. Prim/Env particles preserve both alpha endpoints, trail streams use a bounded active range and release replaced buffers, and source keyed RGB affects textured MoveFX with explicit resets for standalone assets.

The final Orre camera change adjusts only that venue's default side/back distance, shot radius scale, and maximum radius. The old west-side orbit entered a source rock slab; independent comparisons of the original view and radius-48/52 probes confirm an unobstructed battle floor with surrounding rock retained. Targeted tests use real doubles Presenter anchors and guards, including the feet and heads of large actors at eight azimuths. Battler/trainer placement, scale, eye-height range and shared camera code are unchanged.

Native static scene instances now follow the source [`HSD_JObjDispAll`](https://raw.githubusercontent.com/doldecomp/melee/master/src/sysdolphin/baselib/jobj.c) subtree/transform contract. They neither traverse the referenced root's sibling nor globally deduplicate separate placements. Unresolved targets and exhausted budgets now fail scene assembly instead of publishing a partial venue; empty semantic carriers retain their prior behavior. The binary GX fixture covers repeated and hidden instances, rotation, source colors/UVs, actor opt-out, and error propagation. Separate exact-source and GPU checks confirm the Water/Deep results.

Final verification: **113 broad suites passed, zero failed; five native engine suites passed with 2,437 assertions/checks**, for 118 passing suites. Included targeted coverage: Red victory 2,776 checks, Orre camera 712, texture state 49, ground-shadow route parity 144, and native scene instances 48. The actual original release and delivered checkpoint markers were both confirmed as recognized prior identities; global runtime/trainer/audio/MoveFX identities remain unchanged.

The full results are in `suites-final.json` and `native-tests.json`. The five native suites use the real engine checkout with instrumented graphics and an in-memory filesystem. The remaining historical `DoublesDisplayCompatTests` requires unavailable original cbe1/cbe2/cbe3 producers; replacement snapshots were not represented as historical validation. Desktop source/GPU evidence is reported separately. This review does not claim live Android testing, every move in live singles/doubles, or complete GX TEV/animation-controller equivalence.
